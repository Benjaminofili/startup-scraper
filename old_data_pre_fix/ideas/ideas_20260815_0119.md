After analyzing the problems from real users on HackerNews, I've identified the top 5 startup opportunities for Nigerian university students. Here are the ideas:

**1. Open Source Note-Taking App**
* **IDEA NAME**: NoteHub
* **PROBLEM**: Nigerian students need a free and open-source alternative to Notion or Outline for note-taking and organization.
* **SOLUTION**: A simple, user-friendly note-taking app with features like tagging, searching, and collaboration.
* **WHO PAYS**: Students, teachers, and professionals who need a free and reliable note-taking solution.
* **PRICE**: Free, with optional donations (₦100-₦500 per month)
* **FIRST WEEK**:
	1. Research existing open-source note-taking apps and identify key features to include.
	2. Design a user-friendly interface and create a prototype.
	3. Set up a GitHub repository and start building the app.
* **WHY NOW**: The demand for open-source alternatives to popular apps is increasing, and NoteHub can fill this gap in the Nigerian market.
* **FEASIBILITY SCORES**:
	+ Investment: 9/10 (₦0 needed, except for potential server costs)
	+ Passive Income: 8/10 (donations and potential ads)
	+ Team Size: 8/10 (can be built by 1-2 developers)
	+ Time to Market: 7/10 (can be launched in a few weeks)
