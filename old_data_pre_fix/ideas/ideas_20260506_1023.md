**1. Digital Note-Taking App (Open-Source Alternative to Notion)**

1. **IDEA NAME**: NoteHub
2. **PROBLEM**: Students and professionals in Nigeria need a free, open-source, and user-friendly digital note-taking app to organize their notes and research.
3. **SOLUTION**: A mobile and web app that allows users to create, edit, and organize notes, with features like tagging, searching, and collaboration.
4. **WHO PAYS**: Students, researchers, and professionals in Nigeria who need a reliable note-taking app.
5. **PRICE**: Free (open-source), with optional premium features for ₦500/month.
6. **FIRST WEEK**:
	* Step 1: Research existing open-source note-taking apps and identify key features to include.
	* Step 2: Design a user-friendly interface and create a prototype using Figma or Adobe XD.
	* Step 3: Set up a GitHub repository and start building the app using the team's web and Android development skills.
7. **WHY NOW**: The demand for digital note-taking apps is high, and an open-source alternative to Notion can fill the gap in the Nigerian market.
8. **FEASIBILITY SCORES**:
	* Investment: 9/10 (₦0 needed, using open-source resources)
	* Passive Income: 8/10 (optional premium features can generate revenue)
	* Team Size: 8/10 (can be built with a small team of 2-3 developers)
	* Time to Market: 7/10 (can be launched within 2-3 months)
