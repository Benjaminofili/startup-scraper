**1. Open Source Note-Taking App**
* **IDEA NAME**: NoteHub
* **PROBLEM**: Many students and professionals in Nigeria struggle with expensive or limited note-taking apps.
* **SOLUTION**: A free, open-source note-taking app with features similar to Notion or Outline, available on the web and Android.
* **WHO PAYS**: Students, professionals, and businesses looking for affordable note-taking solutions.
* **PRICE**: Free, with optional donations (₦100-500 per month).
* **FIRST WEEK**: 
  1. Research existing open-source note-taking apps and their features.
  2. Set up a GitHub repository and start building the app using existing frameworks.
  3. Create a social media page to gather feedback and interest from potential users.
* **WHY NOW**: The demand for affordable note-taking solutions is high, and an open-source app can attract a large user base.
* **FEASIBILITY SCORES**:
  - Investment: 9/10 (₦0 needed, using open-source frameworks)
  - Passive Income: 8/10 (donations and potential ads)
  - Team Size: 8/10 (can be built by a small team)
  - Time to Market: 7/10 (depending on the complexity of features)
