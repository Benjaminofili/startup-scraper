**1. Open Source Note-Taking App**
* **IDEA NAME**: NoteHub
* **PROBLEM**: Students and professionals in Nigeria need a free and open-source alternative to Notion or Outline for note-taking and organization.
* **SOLUTION**: A simple, user-friendly note-taking app with features like tagging, searching, and collaboration.
* **WHO PAYS**: Students, freelancers, and small business owners in Nigeria.
* **PRICE**: Free, with optional donations (₦100-₦500 per month).
* **FIRST WEEK**: 
 1. Research existing open-source note-taking apps and identify features to include.
 2. Design a user-friendly interface using Figma or Adobe XD.
 3. Set up a GitHub repository and start building the app using existing open-source libraries.
* **WHY NOW**: The demand for open-source alternatives to popular apps is increasing, and NoteHub can fill this gap in the Nigerian market.
* **FEASIBILITY SCORES**:
	+ Investment: 9/10 (₦0 needed, using open-source libraries and free design tools)
	+ Passive Income: 8/10 (donations and potential ads)
	+ Team Size: 8/10 (2-3 developers can build and maintain the app)
	+ Time to Market: 9/10 (can be launched within weeks using existing libraries)
