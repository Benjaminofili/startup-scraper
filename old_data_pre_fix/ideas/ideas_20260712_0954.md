After analyzing the problems from real users, I've identified the top 5 startup opportunities for Nigerian university students. Here are the ideas:

**1. Open Source Note-Taking App**

1. **IDEA NAME**: NoteHub
2. **PROBLEM**: Many students and professionals in Nigeria struggle with expensive or limited note-taking apps.
3. **SOLUTION**: A free, open-source note-taking app with features similar to Notion or Outline, available on Android and web platforms.
4. **WHO PAYS**: Students, professionals, and businesses looking for affordable note-taking solutions.
5. **PRICE**: Free, with optional donations (₦500-₦1000 per month).
6. **FIRST WEEK**:
	* Step 1: Research existing open-source note-taking apps and identify key features to include.
	* Step 2: Design a basic user interface and user experience for the app.
	* Step 3: Set up a GitHub repository and start building the app using existing open-source libraries.
7. **WHY NOW**: With the rise of remote work and online learning, there's a growing need for affordable and flexible note-taking solutions.
8. **FEASIBILITY SCORES**:
	* Investment: 9/10 (₦0 needed, using open-source libraries and free resources)
	* Passive Income: 8/10 (donations and potential ads, but some manual work required)
	* Team Size: 8/10 (can be built with a small team, but may require additional help for maintenance)
	* Time to Market: 9/10 (can be launched within weeks, using existing open-source libraries)
