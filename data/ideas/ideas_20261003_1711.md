## 1. MailMigrate

**Observed problem:** Interest in self‑hosted email is declining, indicating maintenance difficulty.

**Evidence ids:** hn_49328911, hn_49410362

**Affected-user hypothesis:** SMEs that tried self‑hosted email and want easier migration to managed services.

**Solution hypothesis:** A migration tool that imports mailboxes from self‑hosted servers to Gmail/Outlook with minimal steps.

**Monetization hypothesis:** Pay‑per‑migration fee or subscription for bulk migrations.

**Alternatives to verify:**
  - imapsync
  - MigrationWiz
  - Microsoft FastTrack

**Unknowns:**
  - Typical size of mailboxes
  - Technical skill of target users
  - Compliance requirements

**Validation steps:**
  - Create script to move a 100 MB mailbox
  - Run pilot with 3 local businesses
  - Measure time saved vs manual migration

**Model-estimated feasibility:** 68.0/100 (subjective inputs)

## 2. NoteLite

**Observed problem:** Developers seek open‑source, low‑resource alternatives to Obsidian.

**Evidence ids:** hn_48179677, hn_49410362

**Affected-user hypothesis:** Students and knowledge workers in low‑bandwidth regions.

**Solution hypothesis:** A markdown‑based note‑taking Android app that syncs via cheap object storage (e.g., AWS S3 free tier).

**Monetization hypothesis:** Freemium model with premium sync and collaboration features.

**Alternatives to verify:**
  - Obsidian
  - Standard Notes
  - Joplin

**Unknowns:**
  - Sync reliability on object storage
  - User willingness to pay for sync
  - Battery impact

**Validation steps:**
  - Release MVP on Play Store to 20 users
  - Track daily active users and sync failures
  - Offer paid sync upgrade to 5 users

**Model-estimated feasibility:** 66.0/100 (subjective inputs)

## 3. MailBoost

**Observed problem:** Users report email services cutting off attachments, causing frustration.

**Evidence ids:** gh_4543953813, gh_2867573785

**Affected-user hypothesis:** Small business owners and freelancers in Nigeria who rely on email for client files.

**Solution hypothesis:** A self‑hosted email gateway that raises attachment limits and streams large files via temporary links.

**Monetization hypothesis:** Subscription tier for premium storage and API access.

**Alternatives to verify:**
  - Google Drive attachment workarounds
  - WeTransfer
  - ProtonMail attachment limits

**Unknowns:**
  - Willingness to run self‑hosted gateway
  - Actual attachment size needs
  - Compliance with email regulations

**Validation steps:**
  - Deploy a minimal gateway on AWS free tier and test with 25 MB files
  - Survey 20 local freelancers about attachment pain points
  - Measure churn after 1‑month free trial

**Model-estimated feasibility:** 61.0/100 (subjective inputs)

**Alternatives to verify:**

  - MotionEyeOS
  - IP webcam apps

**Unknowns:**

  - User willingness to self‑install
  - Legal restrictions on surveillance

**Validation steps:**

  - Collect footage reliability metrics
  - Ask users if they'd pay for cloud backup

**Model-estimated feasibility:** 60.5/100 (subjective inputs)

## 5. AI‑Box

**Observed problem:** Developers want private AI development environments without sending data to cloud providers.

**Evidence ids:** hn_48346693, hn_49390463

**Affected-user hypothesis:** AI researchers and startups concerned about data privacy.

**Solution hypothesis:** A self‑hosted container that bundles LLM inference and notebooks, deployable on a single VM.

**Monetization hypothesis:** License per VM or paid support plan.

**Alternatives to verify:**
  - LocalAI
  - Ollama
  - RunPod

**Unknowns:**
  - Hardware requirements for decent inference
  - Demand for on‑prem LLMs
  - Support load

**Validation steps:**
  - Spin up on AWS free tier with a small model
  - Invite 5 AI hobbyists to test for 2 weeks
  - Track usage and willingness to upgrade

**Model-estimated feasibility:** 58.0/100 (subjective inputs)
