## 1. **CERT‑VERIFY — Instant Nigerian‑Certificate Authentication**

| **Item** | **Details** |
|---|---|
| **PROBLEM** | “*bola tinubu certificate forgery allegations*” (Google Trends) shows a surge in concern about fake academic certificates in Nigeria. Employers and universities have no cheap, trustworthy way to verify a graduate’s diploma. |
| **SOLUTION** | A web‑API + Android app that lets a university upload a cryptographically‑signed QR‑code / hash for every graduate.  Employers scan the QR‑code (or type a reference number) and receive a real‑time “valid / revoked / not‑found” response.  The back‑end lives on the AWS free tier (S3 + Lambda + DynamoDB). |
| **WHO PAYS** | - **Employers** (HR departments, recruitment agencies)  <br>‑ **Universities** (pay a small monthly fee for the API key & dashboard). |
| **PRICE** | - Employer verification: **₦500 per check** (bulk discount 100‑checks = ₦40 k). <br>‑ University subscription: **₦15 000 / month** (covers up to 5 k graduates). |
| **EXISTING COMPETITORS** | - **VerifyMe**, **TrueCopy**, **Nigerian National Identity Management Commission (NIMC) – digital certificate service** (government‑run, limited rollout). <br>‑ Open‑source blockchain‑based credential projects (e.g., **Blockcerts**) that require heavy integration. |
| **MONETIZATION FIT** | Employers in Nigeria *do* spend on background‑check services (e.g., VerifyMe).  They are accustomed to paying per‑check.  Universities, however, are price‑sensitive and may balk at a subscription unless the service replaces a manual, error‑prone process. |
| **FIRST WEEK** | 1️⃣ Contact the registrar of a local university (e.g., UNILAG) and pitch a **pilot** (no code yet – just a one‑pager). <br>2️⃣ Set up a minimal AWS Lambda + DynamoDB “store‑hash / verify‑hash” endpoint (free tier). <br>3️⃣ Build a simple Android QR‑scanner prototype and a static HTML dashboard for the university admin. |
| **WHY NOW** | The “bola tinubu certificate forgery” story has just trended, meaning media attention and a spike in demand for proof‑of‑authenticity.  No Nigerian‑specific, low‑cost SaaS exists yet; existing players are either government‑only or priced for large corporates. |
| **FEASIBILITY SCORES** | **Investment:** 8/10 (free‑tier AWS, no hardware) <br>**Passive Income:** 6/10 (once API is live, revenue is per‑use) <br>**Team Size:** 9/10 (3 devs can finish MVP) <br>**Time‑to‑Market:** 7/10 (≈4 weeks for pilot) <br>**Competition:** 5/10 (some incumbents but none low‑cost) <br>**Monetization Fit:** 6/10 (employers pay, universities borderline) <br>**Regulatory Risk:** 7/10 (no medical/financial data, just public‑record hashes) |

| **SOLUTION** | A **single‑page progressive web app (PWA)** that pulls exam timetables, result releases, and urgent notices from the university’s existing CMS (via scraping or a simple CSV upload) and pushes **push‑notifications** to Android devices.  Admins get a tiny dashboard to upload a CSV or Google Sheet; the app auto‑generates calendars and reminder alerts. |
| **WHO PAYS** | - **University administrations** (they buy the admin dashboard). <br>‑ **Student unions** (may sponsor for a “premium” version with analytics). |

| **EXISTING COMPETITORS** | - **MyUNILAG portal** (official but not mobile‑push friendly). <br>‑ **WhatsApp groups** (informal, no central control). <br>‑ **Google Classroom** (used for some announcements but not for campus‑wide alerts). |
| **MONETIZATION FIT** | Universities already pay for student‑information systems (e.g., ERP).  Convincing them to add a cheap push‑notification layer is plausible, especially if it reduces the workload of the registrar’s office.  However, many public universities have very tight IT budgets, so price sensitivity is high. |
| **FIRST WEEK** | 1️⃣ Scrape the public UNILAG “Exam Timetable” page and expose it as a JSON endpoint (AWS Lambda). <br>2️⃣ Create a PWA skeleton (React + Workbox) that registers for push‑notifications (Firebase Cloud Messaging – free tier). <br>3️⃣ Draft a one‑page sales sheet and send it to the UNILAG Registrar’s Office. |
| **WHY NOW** | The “unilag” search volume is rising, and the recent staff‑union news suggests that communication channels are under strain.  A mobile‑first notification system solves a clear bottleneck that students are already complaining about on social media. |
| **FEASIBILITY SCORES** | **Investment:** 9/10 (free‑tier AWS + Firebase) <br>**Passive Income:** 5/10 (requires ongoing admin support) <br>**Team Size:** 8/10 (3 devs enough) <br>**Time‑to‑Market:** 8/10 (MVP in 2 weeks) <br>**Competition:** 6/10 (official portal exists, but no push) <br>**Monetization Fit:** 5/10 (budget‑constrained public sector) <br>**Regulatory Risk:** 9/10 (no personal data beyond student IDs) |

## 3. **VOTE‑UNION — Secure, Low‑Cost Online Voting for Academic Staff Unions**

| **Item** | **Details** |
|---|---|
| **PROBLEM** | Google Trends “*academic staff union of universities*” shows that staff unions are actively searching for ways to coordinate.  Current voting (paper ballots, ad‑hoc Google Forms) is insecure and prone to manipulation. |
| **SOLUTION** | A **single‑file web app** (inspired by the Hacker News “Capsule – Single‑file web apps that save their data into SQLite”) that runs entirely in the browser, stores votes encrypted in a **client‑side SQLite DB**, and syncs to a read‑only AWS S3 bucket for audit.  No server‑side code beyond static hosting.  Each union member gets a unique one‑time link. |
| **WHO PAYS** | - **Academic staff unions** (membership fees). <br>‑ **University federations** (if they adopt it for faculty elections). |
| **PRICE** | - Per‑election license: **₦30 000** (covers up to 5 k voters). <br>‑ Optional “audit‑report” add‑on: **₦10 000**. |
| **EXISTING COMPETITORS** | - **Helios Voting** (open‑source, but requires server hosting). <br>‑ **ElectionBuddy** (commercial, pricey). <br>‑ **Google Forms** (free but not secure). |
| **MONETIZATION FIT** | Unions do allocate money for election logistics (printing ballots, venues).  A cheap, transparent digital alternative is attractive, but unions are traditionally risk‑averse and may demand a proof‑of‑concept before paying. |
| **FIRST WEEK** | 1️⃣ Fork the **Capsule** repo and replace its SQLite schema with a simple “vote” table. <br>2️⃣ Add a public‑key signature step (Web Crypto API) to lock the ballot after submission. <br>3️⃣ Create a short demo video and send it to the **Academic Staff Union of Universities (ASUU) Lagos chapter** for feedback. |
| **WHY NOW** | The union‑related search spike coincides with a period of frequent industrial actions; transparent voting can reduce internal disputes and improve public perception.  No Nigerian‑specific, zero‑server voting SaaS exists. |
| **FEASIBILITY SCORES** | **Investment:** 9/10 (static hosting only) <br>**Passive Income:** 4/10 (needs a new election each time) <br>**Team Size:** 9/10 (single‑file app) <br>**Time‑to‑Market:** 8/10 (MVP in <10 days) <br>**Competition:** 5/10 (Helios, ElectionBuddy) <br>**Monetization Fit:** 5/10 (union budgets exist but are cautious) <br>**Regulatory Risk:** 8/10 (no money handling, just votes) |

## 4. **OFFLINE‑STUDY — SQLite‑Backed Mobile Library for Nigerian Curricula**

| **Item** | **Details** |
|---|---|
| **PROBLEM** | Hacker News “*Small programming tricks*” and the general lack of affordable, offline‑first study material in Nigeria (students often have spotty mobile data).  Existing solutions (Google Drive, PDFs) require constant connectivity. |
| **SOLUTION** | An **Android app** that ships with a pre‑loaded SQLite database of **lecture notes, solved examples, and past exam questions** for core subjects (e.g., Physics, Chemistry, Computer Science).  Users can **download additional modules** when they have Wi‑Fi; the app works completely offline thereafter.  Content is curated by university volunteers and stored on AWS S3 (free tier). |
| **WHO PAYS** | - **Students** (especially those in low‑bandwidth regions). <br>‑ **Private tutoring centres** (bulk licences for their pupils). |
| **PRICE** | - Individual student: **₦2 000 / year** (access to all core modules). <br>‑ Tutoring centre bulk: **₦15 000 / year** (up to 50 seats). |
| **EXISTING COMPETITORS** | - **Khan Academy** (online, heavy data). <br>‑ **Nigerian educational YouTube channels** (streaming). <br>‑ **PDF‑sharing WhatsApp groups** (informal, no curation). |
| **MONETIZATION FIT** | Students in Nigeria are **highly price‑sensitive**; many already rely on free WhatsApp groups.  However, a **well‑curated, ad‑free offline library** can command a modest fee, especially if bundled with a “exam‑ready” guarantee.  Tutoring centres are more likely to pay for a reliable resource. |
| **FIRST WEEK** | 1️⃣ Gather 5‑10 high‑quality PDFs from volunteer lecturers (e.g., 1st‑year Physics). <br>2️⃣ Convert them into SQLite tables (title, content, tags) using a simple Python script. <br>3️⃣ Build a minimal Android UI (list → view) and publish a **closed‑beta** on the Play Store (internal test track). |
| **WHY NOW** | Data‑costs in Nigeria remain high; the “small programming tricks” HN thread shows a community appetite for lightweight, self‑contained tools.  No major player offers a **native Android offline library** for Nigerian curricula. |
| **FEASIBILITY SCORES** | **Investment:** 9/10 (free AWS, no server) <br>**Passive Income:** 5/10 (subscription renewal each year) <br>**Team Size:** 8/10 (content curation is the bottleneck) <br>**Time‑to‑Market:** 7/10 (content prep takes weeks) <br>**Competition:** 6/10 (free PDFs exist, but not packaged) <br>**Monetization Fit:** 4/10 (students price‑sensitive) <br>**Regulatory Risk:** 9/10 (no personal data, no licensing issues) |
